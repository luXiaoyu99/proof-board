### Как вернуться к проекту

Windows-вход из каталога: `Start.bat`.
Открыть папку можно через Launchpad → «Папка», описание — «Описание и план».
Сам каталог запускается файлом `04-tools/product-launchpad/Start.cmd`, адрес `http://127.0.0.1:8780`.
Открытие HTML через Live Server не запускает серверы приложений.

### Как принимать следующую доработку

Выбрать один пункт и описать проверяемый результат до изменения кода.
После работы зафиксировать команду/сценарий, результат, дату и оставшиеся ограничения.
Эти пункты — план, не выполненные функции и не подтверждение готовности к продаже.
В этой итерации проверены расположение инструкции и навигация; все приложения заново не запускались.

### Данные и границы

Сначала прочитать применимые AGENTS.md и текущий git diff. Сохранять пользовательские изменения,
оригиналы, базы, медиа и ключи. Проверять изменения на временных данных.
Не запускать автоматически старые установщики, сетевые настройки, операции с оборудованием или публикацию.
Сторонние компоненты сохраняют свои лицензии. Коммиты — только по отдельной прямой команде Дениса;
push, PR, releases и другие записи в удалённые репозитории Денис выполняет вручную.
