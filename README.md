# Proof Board

<img src="icon.svg" width="88" alt="Proof Board">

Версии макета и комментарии по координатам. Локальный инструмент 0.1.0, JavaScript / Node.js.

## Запуск

Node.js 22+. Windows: Start.cmd. macOS/Linux: sh start.sh. Откройте http://127.0.0.1:8813/. Порт можно задать переменной PORT. Сервер слушает только 127.0.0.1 и отдаёт фиксированный список файлов. Не открывайте index.html напрямую: ES modules требуют HTTP.

Нажмите «Пример», затем «Обработать», изучите результат и сохраните нужные файлы по ссылкам экспорта. Для файловых задач выберите разрешённые файлы вручную.

## Данные

- **Макет (необязательно для примера)** (file).
- **Имя версии** (text).
- **Комментарии CSV: x,y,text** (textarea).

Ввод, вычисления и файлы остаются в браузере. Сохранение полей на этом устройстве — только по кнопке; выбранные файлы не сохраняются. «Удалить сохранённое» удаляет только сохранённые поля этого приложения. Локальное хранение не зашифровано: не используйте общий профиль браузера для чувствительных данных. Результат экспорта проверяйте перед переносом в рабочую систему.

## Границы

Многопользовательская работа требует доступа и хранения. Нет сетевой публикации, синхронизации между людьми или автоматических платных запросов. Mac/Linux не проверены на настоящих устройствах.
